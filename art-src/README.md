Original character art for the Xdev200 profile (generated for this repo from Madhusudan's GitHub avatar).
`tools/build_profile.py` turns these into `assets/*.svg`; `tools/build_gifs.py` turns the chibi clips into `assets/*.gif`.
Fonts in `tools/fonts/` are Space Grotesk and JetBrains Mono subsets (SIL Open Font License 1.1). Brand glyphs come from simple-icons (CC0).
